# Portfolio — Graphiste Designer & Communication Digitale

Le site est une page unique : ouvrez `index.html`. Les liens du menu font défiler vers les sections Accueil, À propos, Services, Compétences, Portfolio et Contact.

Les styles sont séparés dans `css/`, avec un fichier distinct par partie. Le menu mobile est géré par `js/menu.js`.

## Remplacer la photo

La photo du portrait se trouve dans `images/portrait-placeholder.png`. Remplacez ce fichier par votre photo en gardant le nom `portrait-placeholder.png`, ou modifiez le chemin `src` de l’image dans `index.html`.

## Images des projets

Les grandes zones d’image du portfolio utilisent des visuels provisoires dans `images/work-*.svg`. Remplacez chaque chemin `src` dans `index.html` par l’emplacement de votre image (par exemple `images/agridigitale.jpg`). Les images sont affichées en entier sans recadrage.

Les textes, coordonnées, liens sociaux et projets de démonstration sont à personnaliser.
